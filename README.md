## 📖 **The Story So Far**

> *I'm Ayush — an AI & Full-Stack Developer from India on a mission to build systems that actually think.*

I didn't start with a plan. I started with **curiosity** — a `console.log("Hello World")` and a lot of broken code. That curiosity turned into an obsession: **how do you make software that solves real problems?**

Today, I build **agentic AI systems** and **production-grade web apps**. My north star is simple:

> **"If it doesn't solve a real problem, it doesn't ship."**

I believe the best developers are part engineer, part designer, part storyteller. So I build with **all three**. Every commit is a small bet that the future is going to be built by people who care about the details.

**Right now, I'm building the future of AI research — one agent at a time.**
